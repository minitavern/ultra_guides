欢迎 ​

应用简介 ​

MiniTavern Ultra（超迷你酒馆）是一款 AI 角色扮演聊天应用。

创造 AI 伙伴，演你的故事——从一张角色卡开始，选你想要的打开方式。

导入或创建角色，使用你自己的云端 API 或本地模型开聊。密钥与数据优先留在本机。

你可以做什么 ​

  1. 创造属于自己的 AI 伙伴
    自定义性格、说话方式与关系设定，让对方像「只懂你」的存在。适合倾诉、陪伴、日常闲聊。

  2. 把爱豆、原作角色「带回身边」
    导入社区角色卡（兼容 SillyTavern 常见规范），用你熟悉的语气继续剧情或日常互动。

  3. 一起演故事、写长线剧情
    用世界书稳住设定，用正则打磨展示效果；会话可单独绑定模型与外观，沉浸感由你掌控。

  4. 用自己的模型，按自己的节奏
    BYOK：自备 API Key 直连主流服务；也可以接家里电脑上的 Ollama / LM Studio。

为什么是 MiniTavern ​

  • 一张卡，两种打开方式：日常陪伴或入戏扮演，同一入口
  • 角色卡优先：PNG / JSON 导入与预览，创作与开聊一条线打通
  • 私有 API：密钥自控，不被单一渠道锁死
  • 进阶可玩：世界书、正则、人设、互动卡面
  • 数据可带走：备份与单聊存档，换机不慌

快速开始 ​

  1. 配置模型：设置 → 模型连接 → 新建并测连，设为默认。
  2. 导入或创造角色：角色卡 → 导入或创建。
  3. 开始聊天：从角色开聊——陪伴或入戏，由你决定。

更细步骤见 第一次使用。本地模型见左侧 本地模型 栏目：入门 · 工具总览 · 30 分钟通关。

常见问题（摘要） ​

Q：MiniTavern Ultra 是什么？
A：一款 AI 角色扮演聊天应用。你可以创造属于自己的 AI 伙伴，也可以导入角色卡入戏扮演；用你自己的 API Key 或本地模型对话。

Q：数据会上传到你们服务器吗？
A：聊天、角色与密钥等默认保存在本机；调用模型时请求发往你配置的第三方或本地地址。详见 隐私协议。

Q：没有 API 也能玩吗？
A：需要自行准备云端 Key，或按 本地模型 在电脑上搭建后再连接手机。
