OpenRouter ​

글로벌 모델 집약 게이트웨이: Key 하나로 다수 모델. 일부는 무료 풀（ID에 :free, 또는 Free 표기）— 개인 체험, OSS 비교, 저빈도 롤플레이에 적합. 공식: Free Models; 제3자: openairouter.net/free-models（비공식, 콘솔 우선）.

무료 목록·RPM/일 한도는 변합니다. openrouter.ai/models와 계정 페이지 기준.

공식과 입구 ​

자원주소
공식openrouter.ai
API Keyopenrouter.ai/keys
Free Modelsopenrouter.ai/collections/free-models
광장（Free）openrouter.ai/models?q=free
커뮤니티 요약（제3자）openairouter.net/free-models
API Base URLhttps://openrouter.ai/api/v1（MiniTavern OpenRouter 선택 시 보통 수동 불필요）

무료 받기 ​

  1. openrouter.ai/keys 가입·Key（보통 카드 불필요）.
  2. Free Models 또는 광장에서 Model ID 복사（:free 주의）.
  3. MiniTavern OpenRouter, Key 붙여넣기, 해당 ID.
항목설명
무료ID에 :free, 또는 컬렉션 $0; 자동 라우트 openrouter/free
속도약 20 RPM / 약 50회/일; 일회 충전 약 $10+ 후 무료 일 한도 약 1000회/일（공식 기준）
카드무료는 보통 불필요; 충전은 한도 상향·유료 호출용
프라이버시일부 무료 업스트림은 프롬프트로 개선; OpenRouter 설정에서 프라이버시. Poolside Laguna 등은 학습 가능 명시

모델 목록 ​

컬렉션·공개 요약의 흔한 텍스트 / 비전 ID（약 2026-08）; 공식 기준. ID 대소문자 구분, :free 생략 금지（항목에 없을 때 제외）.

이미지 / 비디오 ​

  • 이미지: OpenRouter Image Models; 무료는 모델 페이지. MiniTavern 이미지 연결 OpenRouter 가능.
  • 비디오: Video Models; App 내장 비디오 없음.
  • Lyria 등 음악 생성은 채팅/이미지와 무관 — 대화 모델로 쓰지 말 것.

MiniTavern 입력 ​

일반: 모델 연결.

채팅 ​

경로: 설정 → 모델 → 모델 연결 → 새로 만들기

  1. OpenRouter（프리셋 Base URL）
  2. API Key
  3. 예 meta-llama/llama-3.3-70b-instruct:free 또는 openrouter/free
  4. 테스트 → 기본값

Custom (OpenAI) + Base URL https://openrouter.ai/api/v1도 가능; App 프리셋 우선.

이미지 ​

경로: 설정 → 이미지 생성 → 이미지 연결 → OpenRouter, 광장에서 이미지·무료（또는 과금 허용）ID. 더 안정적인 무료: Agnes AI, AIHubMix.
