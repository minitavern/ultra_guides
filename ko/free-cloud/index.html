무료 클라우드 ​

MiniTavern은 BYOK(직접 키 사용) 입니다. 앱이 클라우드 한도를 주지 않으며, 각 벤더·추론 플랫폼 API Key를 직접 등록합니다.
여기에서는 흔한 무료/체험 한도와 App 입력 방법을 정리합니다. 한도와 정책은 바뀌므로 각 공식 콘솔의 실시간 표시를 기준으로 하세요.

보안: API Key는 비밀번호와 같습니다. App 기기 내 저장에만 넣고, 채팅·스크린샷·공개 저장소에 올리지 마세요.

MiniTavern에서 입력하기 ​

경로: 설정 → 모델 → 모델 연결 → 새로 만들기

  1. 모델 플랫폼을 맞게 선택（아래 「App 플랫폼」 열）.
  2. API Key 붙여넣기. Custom이면 Base URL도.
  3. 모델 ID 선택/직접 입력（벤더 문서와 완전 일치, 대소문자 구분）.
  4. 테스트 → 성공 후 기본값으로 설정.

중국 본토에서 자주 씀（직결 우선） ​

Zhipu AI (GLM) ​

적합한 경우: 장기 무료로 대화 통하기（Flash 계열）, 중국어 롤플레이에 유리.

항목내용
공식/Keyopen.bigmodel.cn → 콘솔 → API Keys
무료GLM-*-Flash 등 영구 무료; 신규는 체험 한도 있는 경우 많음（콘솔 확인）
카드 연동보통 불필요
Base URLhttps://open.bigmodel.cn/api/paas/v4
모델 예glm-4.5-flash, glm-4.7-flash（모델 광장 명칭 기준）
AppCustom (OpenAI)

절차: 가입 → API Key → Custom (OpenAI) → Base URL·Key → Flash ID → 연결 테스트.

SiliconFlow（硅基流動） ​

적합한 경우: Key 하나로 여러 OSS 채팅; 일부 이미지 무료 모델.

항목내용
공식/Keycloud.siliconflow.cn → 계정 → API 키
무료무료 모델은 과금 없음（이름에 Pro/ 없음）; 실명 후 전체 무료 모델
제한모델별 고정 RPM/TPM; Rate Limits
Base URLhttps://api.siliconflow.cn/v1
모델 예광장 「免费」 태그, 예 Qwen/Qwen3-8B（목록 변동）
AppCustom (OpenAI)

주의: 동명이 무료와 Pro/... 유료가 공존. 잘못 넣으면 과금. 청구서에서 무료 모델 소모는 0이어야 함.

통의천문 · 알리바바 클라우드 백련 ​

적합한 경우: 공식 Qwen 계열; MiniTavern에 Qwen 프리셋 있음.

항목내용
개통백련 콘솔（화북 2/베이징）약관 동의 후 자동 개통
무료신규 무료 한도: 대부분 모델 약 100만 Token/모델, 약 90일; 모델 간 공유 불가
Key백련 → API-Key; 일반 Key（Token/Coding Plan 전용은 무료 한도를 소모하지 않음）
AppQwen（국내 프리셋; 국제 사이트 전환 가능）
과금 방지콘솔에서 「무료 한도 소진 시 중지」 켜기

공식: 신규 무료 한도. 한도 종료·만료 후 호출은 과금.

이미지（만상/Qwen-Image 등）가 신규 한도 대상이면 설정 → 이미지 생성 → 이미지 연결 → Qwen. 무료 여부는 콘솔 한도 표시 확인.

항목내용

무료신규에 가입 보너스/체험이 있는 경우가 많음（금액은 콘솔）
AppDeepSeek
모델 예deepseek-v4-flash, deepseek-v4-pro（공식）

보너스 후 종량. 잔액 없으면 실패.

Google Gemini ​

멀티모달 텍스트·긴 컨텍스트. 텍스트 무료 티어가 비교적 넉넉.

항목내용
Keyaistudio.google.com/app/apikey
무료일부 Gemini Flash/Lite 텍스트 Free tier（RPM/RPD는 AI Studio）
카드텍스트 무료는 보통 불필요; 최신 이미지 API 다수는 Free 없음
지역EU/영국/스위스 등은 무료 불가일 수 있음
프라이버시무료 프롬프트가 제품 개선에 쓰일 수 있음
AppGemini(Google)

채팅은 텍스트 모델（예 gemini-flash-latest）. tts/image 전용 ID 금지 — 테스트는 TEXT를 요구하고 TTS는 AUDIO만 → response modalities (TEXT) is not supported.

HTTP 404+no longer available to new users: ID 폐기/신규 비공개（예 gemini-2.5-flash-lite）. 목록 갱신 후 온라인 Flash/Lite（예 gemini-flash-latest）선택.

HTTP 429+generate_content_free_tier_requests（자주 limit: 20）: 무료 분당 한도. Please retry in … 대기. ai.dev/rate-limit.

이미지: Gemini App과 Developer API 한도가 다름. API 이미지는 Free 불가 표기가 많음. 채팅=Gemini, 이미지=집 A1111/ComfyUI 조합이 흔함 — 이미지 모델 배포.

무료:free/컬렉션 Free; 약 20 RPM, 일 요청 제한; 충전 시 일 한도 상향 가능
AppOpenRouter
모델 예openrouter/free, meta-llama/llama-3.3-70b-instruct:free, openai/gpt-oss-20b:free

주의: 무료 업스트림이 프롬프트를 학습에 쓸 수 있음. HTTP 429: Provider returned error → 다른 :free, 재시도, 또는 BYOK.

사용 팁과 문제 해결 ​

  1. 먼저 연결 테스트: 실패 시 「상세」→ 오류 코드.
  2. 429 / 속도 제한: 가벼운 모델, 기억 단축, 다른 무료 백엔드.
  3. 갑작스러운 과금: Pro/ 모델? 백련 중지 미설정? 보너스 소진?
  4. 프라이버시: 무료 티어는 로그 학습이 흔함 — 민감 내용은 로컬.
  5. 한도 변경: 수치는 조사 시점 참고. 색인: FreeLLM（awesome-freellm-apis · freellm.net）.
