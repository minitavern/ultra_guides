# ultra_guides（Pages 产物仓）

本目录与 `tavernmm` **同级**，仅存放 VitePress 构建结果，推送到 [minitavern/ultra_guides](https://github.com/minitavern/ultra_guides) 的 `gh-pages`。

- **不要**在此编辑教程正文；改 `tavernmm/guides/**/*.md`
- 同步：`cd ../tavernmm/guides && yarn sync`
- 发布：先配置 `.publish.env`（见 `.publish.env.example`），再 `./publish.sh`

站点：https://minitavern.github.io/ultra_guides/
