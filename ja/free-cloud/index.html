無料クラウド ​

MiniTavern は BYOK（自分の鍵を使う） です。アプリ側のクラウド枠はなく、各社・推論プラットフォームの API Key を自分で用意します。
ここではよくある 無料／体験枠 と App への記入方法をまとめます。枠や規約は変わるため、各公式コンソールの表示を正としてください。

安全：API Key はパスワードと同じです。App の端末内保存にだけ入れ、チャット・スクショ・公開リポジトリに出さないでください。

まず一番早いルートを選ぶ ​

Key の一般手順は モデル接続。ローカルは ローカルモデル · 30 分クイックスタート。

MiniTavern での記入方法 ​

経路：設定 → モデル → モデル接続 → 新規

  1. モデルプラットフォームを正しく選ぶ（下表「App プラットフォーム」列）。
  2. API Key を貼る。カスタムの場合は Base URL も。
  3. モデル ID を選択／手入力（ベンダー文書と完全一致、大文字小文字区別）。
  4. テスト → 成功したら デフォルト に設定。
ベンダーApp プラットフォームBase URL（一般）説明

智譜 AI (GLM) ​

向いている人：長期無料で会話を通したい（Flash 系）、中国語ロールプレイ向き。

項目内容
公式／Keyopen.bigmodel.cn → コンソール → API Keys
無料GLM-*-Flash など永久無料；新規は体験枠があること多（コンソール確認）
カード紐付け通常不要
Base URLhttps://open.bigmodel.cn/api/paas/v4
モデル例glm-4.5-flash、glm-4.7-flash（モデル広場の名称に従う）
AppCustom (OpenAI)

手順：登録 → API Key 作成 → Custom (OpenAI) → Base URL と Key → Flash 系 ID → 接続テスト。

SiliconFlow（硅基流動） ​

向いている人：1 Key で複数 OSS チャット；画像にも無料枠がある場合あり。

項目内容
公式／Keycloud.siliconflow.cn → アカウント → API キー
無料無料モデルは課金なし（名前に Pro/ なし）；実名後に全無料モデル利用可
制限モデル固定 RPM/TPM；Rate Limits
Base URLhttps://api.siliconflow.cn/v1
モデル例広場の「免费」タグ、例 Qwen/Qwen3-8B（一覧は変動）
AppCustom (OpenAI)

注意：同名でも無料と Pro/... 課金版がある。誤りは課金。請求で無料モデル消費は 0 のはず。

通義千問 · アリババクラウド百煉 ​

向いている人：公式 Qwen 系；MiniTavern に Qwen プリセットあり。

項目内容
開通百煉コンソール（華北 2／北京）で規約同意後自動開通
無料新規無料枠：多くのモデルで約 100 万 Token／モデル、約 90 日；モデル間で共有不可
Key百煉 → API-Key；汎用 Key（Token Plan／Coding Plan 専用は無料枠を消費しない）
AppQwen（国内プリセット；国際サイト切替可）
課金防止コンソールで「無料枠終了で停止」を有効化

公式：新規無料枠。枠終了・期限後は従量課金。

画像（万相／Qwen-Image など）が新規枠対象なら 設定 → 画像生成 → 画像接続 → Qwen。無料かはコンソールの枠表示で確認。

Google Gemini ​

マルチモーダルテキスト・長コンテキスト。テキスト無料枠は比較的厚い。

項目内容
Keyaistudio.google.com/app/apikey
無料一部 Gemini Flash／Lite テキストに Free tier（RPM／RPD は AI Studio 表示）
カードテキスト無料は通常不要；新しい画像モデルの多くは Free なし
地域EU／英国／スイス等は無料枠不可の場合あり
プライバシー無料枠のプロンプトが製品改善に使われる場合あり
AppGemini(Google)

チャットはテキストモデル（例 gemini-flash-latest）。tts／image 付き専用 ID は選ばない — テストは TEXT を要求し、TTS は AUDIO のみ → response modalities (TEXT) is not supported。

HTTP 404＋no longer available to new users：ID 廃止／新規非公開（例 gemini-2.5-flash-lite）。最新一覧を取得し、稼働中の Flash／Lite（例 gemini-flash-latest）へ。

HTTP 429＋generate_content_free_tier_requests（よく limit: 20）：無料枠の分あたり上限。Please retry in … に従う。ai.dev/rate-limit。

画像：Gemini App と Developer API は枠が別。API 画像は Free 不可表記が多い。チャット＝Gemini、画像＝自宅 A1111／ComfyUI が定番 — 画像モデル展開。

経路費用説明

チャットと画像接続は分離可：例・チャット＝智譜 Flash、画像＝自宅 ComfyUI。

使い方のコツとトラブル ​

  1. 先に接続テスト：失敗時は「詳細」→ エラーコード。
  2. 429／レート制限：軽いモデル、記憶短縮、別無料枠。
  3. 突然の課金：Pro/ モデル？百煉の停止未設定？ボーナス切れ？
  4. プライバシー：無料枠はログ改善利用が多い — 機密は ローカル。
  5. 枠の変更：数値は調査時点の目安。索引は FreeLLM（awesome-freellm-apis · freellm.net）。
