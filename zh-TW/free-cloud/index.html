免費雲端 ​

MiniTavern 是 BYOK（自備金鑰）：不送雲端額度，需你自己註冊廠商或推理平台的 API Key。
本文彙總常見免費／試用額度與填入 App 的方法；額度與政策會變動，以各官網控制台即時顯示為準。

安全提醒：API Key 等同密碼。只填進 App 本機安全儲存，不要發到群聊、截圖公開或提交到公開倉庫。

填 Key 的通用步驟見 模型連線。本機部署見 部署本地模型 · 30 分鐘通關。

在 MiniTavern 裡怎麼填 ​

路徑：設定 → 模型 → 模型連線 → 新建

  1. 選對 模型平台（下表「App 平台」欄）。
  2. 貼上 API Key；自訂平台再填 Base URL。
  3. 選擇或手填 模型 ID（必須與廠商文件一致，大小寫敏感）。
  4. 點 測試 → 成功後再設為 預設。

國內常用（大陸直連優先） ​

智譜 AI (GLM) ​

適合：想長期免費跑通對話（Flash 系列），中文角色扮演友好。

項目說明
官網／Keyopen.bigmodel.cn → 控制台 → API Keys
免費方式GLM-*-Flash 等永久免費模型；新用戶常另有體驗額度（以控制台為準）
綁卡通常不需要
Base URLhttps://open.bigmodel.cn/api/paas/v4
模型示例glm-4.5-flash、glm-4.7-flash（名稱以模型廣場為準）
App自訂 (OpenAI)

步驟：註冊 → 建立 API Key → 在 App 選自訂 OpenAI → 填 Base URL 與 Key → 模型填 Flash 系列 ID → 測連。

矽基流動 (SiliconFlow) ​

適合：一個 Key 試用多種開源聊天模型；部分圖像模型也有免費檔。

項目說明
官網／Keycloud.siliconflow.cn → 帳戶 → API 金鑰
免費方式免費模型呼叫不計費（名稱不含 Pro/ 前綴）；需完成實名後可用全部免費模型
限速按模型固定 RPM/TPM；見官方 Rate Limits
Base URLhttps://api.siliconflow.cn/v1
模型示例在模型廣場選「免費」標籤，如 Qwen/Qwen3-8B 等（列表會變）
App自訂 (OpenAI)

注意：同名模型可能有免費版與 Pro/... 收費版，填錯會扣費。帳單裡免費模型消耗應為 0。

通義千問 · 阿里雲百鍊 ​

適合：想用官方 Qwen 系列；MiniTavern 有 Qwen 預設。

項目說明
開通阿里雲百鍊控制台（華北 2／北京）同意協議後自動開通
免費方式新人免費額度：多數模型約 100 萬 Token／模型，約 90 天有效；模型間額度不互通
Key百鍊 → API-Key；請用通用 Key（Token Plan／Coding Plan 專屬 Key 不消耗免費額度）
AppQwen（國內站預設；國際站可切換）
防扣費控制台開啟「免費額度用完即停」，避免額度耗盡後按量扣款

官方說明：新人免費額度。額度耗盡或過期後繼續呼叫會產生費用。

生圖（萬相／Qwen-Image 等）若參與新人額度，可在 設定 → 生圖 → 生圖連線 選 Qwen 平台；是否免費以控制台該模型額度條為準。

Base URLhttps://apihub.agnes-ai.com/v1
文本示例agnes-2.5-flash
生圖示例agnes-image-2.1-flash（生圖連線選 自訂 (OpenAI Images)）

OpenCode Zen ​

適合：想用 OpenCode 精選閘道上的 Free 文本模型（如 mimo-v2.5-free）；多數旗艦仍按量付費，注意自動儲值。

完整說明見專頁：OpenCode Zen。

AIHubMix ​

適合：一把 Key 試用多款平台補貼的 *-free 模型（含 GPT／Gemini／GLM 等）及 GPT-Image-2-free 生圖；通常無需綁卡。

完整說明見專頁：AIHubMix。

項目說明
官網／Keyaihubmix.com · 免費模型文
免費方式模型 ID 以 -free 結尾；按模型 RPM／日額度
Base URLhttps://aihubmix.com/v1
文本示例gpt-4o-free、gpt-5.5-free、coding-glm-5.1-free
生圖示例gpt-image-2-free（自訂 (OpenAI Images)）
App自訂 (OpenAI)／自訂 (OpenAI Images)

Google Gemini ​

適合：多模態文本、長上下文；文本免費檔較慷慨。

項目說明
Keyaistudio.google.com/app/apikey
免費方式部分 Gemini Flash／Lite 文本模型有 Free tier（RPM／RPD 以 AI Studio 帳戶內顯示為準）
綁卡文本免費檔通常不需要；生圖類最新模型多數無 Free tier
地區歐盟／英國／瑞士等可能不可用免費檔
隱私免費檔提示詞可能用於改進產品（見 Google 條款）
AppGemini(Google)

聊天請選文本模型（如 gemini-flash-latest）。不要選名稱帶 tts、image 的專用 ID：測連會請求文字回覆，TTS 只輸出 AUDIO，會報 response modalities (TEXT) is not supported。語音／生圖到對應功能裡設定。

若測連／發送返回 HTTP 404 且含 no longer available to new users：該模型 ID 已下線或不再向新用戶開放（如 gemini-2.5-flash-lite）。在模型連線中拉取最新列表，改選仍在線的 Flash／Lite（如 gemini-flash-latest）。不必改用 Interactions API。

若發送失敗提示 HTTP 429 且含 generate_content_free_tier_requests（常見 limit: 20）：這是免費檔每分鐘請求次數用盡，按 Please retry in … 等待後再發即可。用量見 ai.dev/rate-limit；需要更高限額可在 AI Studio 開通結算。這與「帳戶沒錢」或專案月度消費上限不同。

生圖：Gemini App 網頁端與 Developer API 額度不同；API 側圖像模型定價頁常標註 Free tier 不可用。聊天用 Gemini、生圖用本地 A1111／ComfyUI 是常見組合，見 生圖模型部署。

免費方式:free／合集 Free；預設可約 20 RPM、日請求有限；儲值可提高免費日限額（以官方為準）

注意：免費上游可能記錄提示詞用於訓練。若 HTTP 429: Provider returned error：換其它 :free、稍後重試，或 BYOK。

免費生圖怎麼配 ​

路徑費用說明
本機 A1111／ComfyUI電費 + 顯示卡不限張數；手機連電腦區域網
矽基流動免費圖像模型免費模型 0 元生圖連線選 自訂 (OpenAI Images)，Base URL 同矽基 …/v1，模型選免費圖像 ID
Agnes AI 圖像 FlashFree Access生圖連線選 自訂 (OpenAI Images)，Base URL https://apihub.agnes-ai.com/v1，如 agnes-image-2.1-flash
AIHubMix*-free 圖像模型生圖連線選 自訂 (OpenAI Images)，Base URL https://aihubmix.com/v1，如 gpt-image-2-free

聊天模型與生圖連線可分開設定：例如聊天用智譜 Flash，生圖用家裡的 ComfyUI。

使用建議與排錯 ​

  1. 先測連再開聊：失敗時點「查看詳情」，對照 錯誤代碼排錯。
  2. 429／限流：換輕量模型、降記憶長度、錯峰，或再備一個免費平台。
  3. 突然扣費：檢查是否用了 Pro/ 收費模型、百鍊未開「用完即停」、或贈金已耗盡。
  4. 隱私：免費檔常允許廠商用日誌改進模型；敏感內容優先 部署本地模型。
  5. 額度變更：本文數字為調研時常見值；以官網為準。更全的廠商／模型索引見 FreeLLM 目錄（awesome-freellm-apis · freellm.net，非官方、每日更新）。
