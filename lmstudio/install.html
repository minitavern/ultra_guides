安装 LM Studio ​

LM Studio 提供图形界面：下载模型、加载、并开启 OpenAI 兼容 的 Local Server。

安装 ​

  1. 打开 https://lmstudio.ai/ 下载 Windows 或 macOS 安装包。
  2. 安装并启动。
  3. 在应用内 Discover / 探索 搜索并下载一个较小的对话模型（先用于通关验证）。

加载模型 ​

  1. 打开 Chat 或模型管理页。
  2. 选择已下载的模型并加载到内存（注意显存/内存占用）。
  3. 本机聊天窗口能正常回复，再开服务器给手机用。
