开启局域网访问（Ollama） ​

默认情况下，Ollama 往往只监听本机。手机要连电脑，必须让服务监听 所有网卡（0.0.0.0），并放行防火墙端口。

设置 OLLAMA_HOST ​

Windows ​

  1. 在开始菜单搜索「环境变量」→「编辑系统环境变量」→「环境变量」。
  2. 在「用户变量」或「系统变量」中新建：
变量名变量值
OLLAMA_HOST0.0.0.0
  1. 确定保存后，完全退出并重新打开 Ollama（托盘图标退出再启动）。

也可在 PowerShell（当前会话临时生效）中：

powershell
$env:OLLAMA_HOST = "0.0.0.0"
# 然后重启 ollama 应用或服务

macOS ​

临时（当前终端会话）：

bash
launchctl setenv OLLAMA_HOST 0.0.0.0

然后退出并重新打开 Ollama 应用。若重启后失效，可写入 shell 配置或使用 LaunchAgent；也可用：

bash
export OLLAMA_HOST=0.0.0.0

并确保 Ollama 服务在该环境下启动。最稳妥仍是：设置环境变量后重启 Ollama。

防火墙放行端口 11434 ​

  • Windows：系统设置 → 隐私和安全性 → Windows 安全中心 → 防火墙 → 允许应用通过防火墙；或新建入站规则放行 TCP 11434。
  • macOS：系统设置 → 网络 → 防火墙；首次访问时允许 Ollama，或对端口放行。

验证局域网 ​

  1. 查电脑 IP（见 快速开始 Step 4）。
  2. 用同一 Wi‑Fi 下另一台设备的浏览器访问：
text
http://YOUR_PC_IP:11434

能打开或返回 Ollama 相关响应，说明局域网已通。

给 MiniTavern 用的地址 ​

text
http://YOUR_PC_IP:11434/v1

注意：

  • 用局域网 IP，不要用 localhost
  • 建议带 /v1 后缀（OpenAI 兼容路径）
