下载与选择模型 ​

拉取模型 ​

bash
ollama pull <模型名>

示例：

bash
ollama pull llama3.2:3b
ollama pull qwen2.5:7b

查看已下载：

bash
ollama list

本机试聊：

bash
ollama run llama3.2:3b

怎么选大小 ​

大致规模内存/显存粗略参考说明
1B–3B约 4–8GB适合验证通路、轻量回复
7B–8B约 8–16GB角色扮演常用甜点区
13B+16GB+质量更好，更吃硬件

量化越小（如 Q4）越省内存、速度更快，质量略降。Ollama 的 tag（如 :3b、:7b）已按官方默认量化打包，新手直接用官方名即可。

角色扮演提示 ​

  • 优先选社区口碑较好的对话/指令模型；纯补全基座模型可能不适合聊天格式。
  • 在 MiniTavern 里填写的 模型名 必须与 ollama list 左列名称完全一致（含 tag）。
