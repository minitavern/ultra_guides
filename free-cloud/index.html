免费云端 ​

MiniTavern 是 BYOK（自备密钥）：不送云端额度，需你自己注册厂商或推理平台的 API Key。
本文汇总常见免费 / 试用额度与填入 App 的方法；额度与政策会变动，以各官网控制台实时显示为准。

安全提醒：API Key 等同密码。只填进 App 本机安全存储，不要发到群聊、截图公开或提交到公开仓库。

在 MiniTavern 里怎么填 ​

路径：设置 → 模型 → 模型连接 → 新建

  1. 选对 模型平台（下表「App 平台」列）。
  2. 粘贴 API Key；自定义平台再填 Base URL。
  3. 选择或手填 模型 ID（必须与厂商文档一致，大小写敏感）。
  4. 点 测试 → 成功后再设为 默认。

国内常用（大陆直连优先） ​

智谱 AI (GLM) ​

适合：想长期免费跑通对话（Flash 系列），中文角色扮演友好。

项目说明
官网 / Keyopen.bigmodel.cn → 控制台 → API Keys
免费方式GLM-*-Flash 等永久免费模型；新用户常另有体验额度（以控制台为准）
绑卡通常不需要
Base URLhttps://open.bigmodel.cn/api/paas/v4
模型示例glm-4.5-flash、glm-4.7-flash（名称以模型广场为准）
App自定义 (OpenAI)

步骤：注册 → 创建 API Key → 在 App 选自定义 OpenAI → 填 Base URL 与 Key → 模型填 Flash 系列 ID → 测连。

硅基流动 (SiliconFlow) ​

适合：一个 Key 试用多种开源聊天模型；部分图像模型也有免费档。

项目说明
官网 / Keycloud.siliconflow.cn → 账户 → API 密钥
免费方式免费模型调用不计费（名称不含 Pro/ 前缀）；需完成实名后可用全部免费模型
限速按模型固定 RPM/TPM；见官方 Rate Limits
Base URLhttps://api.siliconflow.cn/v1
模型示例在模型广场选「免费」标签，如 Qwen/Qwen3-8B 等（列表会变）
App自定义 (OpenAI)

注意：同名模型可能有免费版与 Pro/... 收费版，填错会扣费。账单里免费模型消耗应为 0。

通义千问 · 阿里云百炼 ​

适合：想用官方 Qwen 系列；MiniTavern 有 Qwen 预设。

项目说明
开通阿里云百炼控制台（华北 2 / 北京）同意协议后自动开通
免费方式新人免费额度：多数模型约 100 万 Token / 模型，约 90 天有效；模型间额度不互通
Key百炼 → API-Key；请用通用 Key（Token Plan / Coding Plan 专属 Key 不消耗免费额度）
AppQwen（国内站预设；国际站可切换）
防扣费控制台开启「免费额度用完即停」，避免额度耗尽后按量扣款

官方说明：新人免费额度。额度耗尽或过期后继续调用会产生费用。

生图（万相 / Qwen-Image 等）若参与新人额度，可在 设置 → 生图 → 生图连接 选 Qwen 平台；是否免费以控制台该模型额度条为准。

DeepSeek ​

适合：推理、长文、高性价比；额度用完后很便宜，但不是永久 0 元。

项目说明
官网 / Keyplatform.deepseek.com → API Keys
免费方式新用户通常有注册赠金 / 体验额度（金额与规则以控制台为准，会调整）
AppDeepSeek
模型示例deepseek-v4-flash、deepseek-v4-pro（以官方文档为准）

赠金用尽后按量计费；账户无余额时请求会失败。

国际 / 聚合平台 ​

Google Gemini ​

适合：多模态文本、长上下文；文本免费档较慷慨。

项目说明
Keyaistudio.google.com/app/apikey
免费方式部分 Gemini Flash / Lite 文本模型有 Free tier（RPM / RPD 以 AI Studio 账户内显示为准）
绑卡文本免费档通常不需要；生图类最新模型多数无 Free tier
地区欧盟 / 英国 / 瑞士等可能不可用免费档
隐私免费档提示词可能用于改进产品（见 Google 条款）
AppGemini(Google)

聊天请选文本模型（如 gemini-flash-latest）。不要选名称带 tts、image 的专用 ID：测连会请求文字回复，TTS 只输出 AUDIO，会报 response modalities (TEXT) is not supported。语音/生图到对应功能里配置。

若测连/发送返回 HTTP 404 且含 no longer available to new users：该模型 ID 已下线或不再向新用户开放（如 gemini-2.5-flash-lite）。在模型连接中拉取最新列表，改选仍在线的 Flash / Lite（如 gemini-flash-latest）。不必改用 Interactions API。

若发送失败提示 HTTP 429 且含 generate_content_free_tier_requests（常见 limit: 20）：这是免费档每分钟请求次数用尽，按 Please retry in … 等待后再发即可。用量见 ai.dev/rate-limit；需要更高限额可在 AI Studio 开通结算。这与「账户没钱」或项目月度消费上限不同。

生图：Gemini App 网页端与 Developer API 额度不同；API 侧图像模型定价页常标注 Free tier 不可用。聊天用 Gemini、生图用本地 A1111/ComfyUI 是常见组合，见 生图模型部署。

OpenRouter ​

适合：一个 Key 试用大量开源 / 第三方模型；模型 ID 以 :free 结尾表示走免费池。

项目说明
Keyopenrouter.ai/keys
免费方式带 :free 的模型；默认约 20 RPM / 50 次/天；一次性充值 $10+ 后免费模型日限额可升至约 1000 次/天（规则以官方为准）
AppOpenRouter
模型示例在 Models 筛选 Free，如 openai/gpt-oss-20b:free
路由也可试 openrouter/free 等免费路由（可用性会变）

注意：免费上游可能记录提示词用于训练；可在 OpenRouter 设置中查看隐私选项。

若发送失败提示 HTTP 429: Provider returned error：这是上游（如 Google 免费池）拒绝，不是密钥写错，也不一定是本机发太快。稍后再试、换其他厂商的空闲模型，或在 OpenRouter BYOK 绑定自己的上游 Key。

免费生图怎么配 ​

路径费用说明
本机 A1111 / ComfyUI电费 + 显卡不限张数；手机连电脑局域网
硅基流动免费图像模型免费模型 0 元生图连接选 自定义 (OpenAI Images)，Base URL 同硅基 …/v1，模型选免费图像 ID
通义万相 / Qwen 生图看百炼该模型是否有免费额度设置 → 生图 → 生图连接 → Qwen
OpenAI / 多数 Gemini 图像 API通常付费无稳定 Free tier 时不要当「免费生图」

聊天模型与生图连接可分开配置：例如聊天用智谱 Flash，生图用家里的 ComfyUI。

使用建议与排错 ​

  1. 先测连再开聊：失败时点「查看详情」，对照 错误代码排错。
  2. 429 / 限流：换轻量模型、降记忆长度、错峰，或再备一个免费平台。
  3. 突然扣费：检查是否用了 Pro/ 收费模型、百炼未开「用完即停」、或赠金已耗尽。
  4. 隐私：免费档常允许厂商用日志改进模型；敏感内容优先 部署本地模型。
  5. 额度变更：本文数字为调研时常见值；以官网为准。社区汇总可参考 awesome-free-llm-apis（非官方）。
