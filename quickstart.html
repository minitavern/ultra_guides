30 分钟通关 ​

目标：从零到在 MiniTavern 里收到本地模型的第一条回复。

步骤大约用时做什么
10–5 min选工具：Ollama 或 LM Studio
25–15 min安装并下载一个小模型
315–20 min开启局域网 / Local Server
420–25 min查电脑局域网 IP
525–30 min在 MiniTavern 新建连接并测连

Step 1：选工具 ​

  • 想最快：选 Ollama 或 LM Studio
  • 角色扮演向：可后续换 KoboldCPP
  • 已有 GGUF：可用 llama.cpp

完整对比见 工具总览。下面以 Ollama 为例写通关步骤；其它工具把「拉模型 / 开服务」换成对应章节即可，第 5 步相同。

Step 2：安装并拉一个小模型 ​

  1. 按 Ollama 安装 装好。
  2. 打开终端，执行（示例模型，体积相对小，适合验证通路）：
bash
ollama pull llama3.2:3b
  1. 确认本机可用：
bash
ollama run llama3.2:3b

能对话后输入 /bye 退出即可。更多模型选择见 下载与选择模型。

Step 3：开启局域网访问 ​

按 开启局域网访问 设置 OLLAMA_HOST=0.0.0.0，并放行防火墙端口 11434。

完成后，在电脑本机浏览器访问（应有响应，不一定是漂亮网页）：

http://127.0.0.1:11434

Step 4：查电脑局域网 IP ​

  • Windows：Win + R → cmd → 输入 ipconfig，找「无线局域网适配器」下的 IPv4 地址（形如 192.168.x.x）。
  • macOS：系统设置 → 网络 → 当前 Wi‑Fi → 详情里的 IP；或终端执行 ipconfig getifaddr en0。

记下这个 IP，后面记作 YOUR_PC_IP。

Step 5：在 MiniTavern 里配置 ​

  1. 打开 App → 设置 → 模型连接 → 新建。
  2. 平台选 自定义 / OpenAI 兼容（以 App 内实际选项名为准）。
  3. 填写：
字段示例（Ollama）
Base URLhttp://YOUR_PC_IP:11434/v1
API Key可留空或填任意占位（本地通常不校验）
模型名llama3.2:3b（与 ollama list 一致）
  1. 保存并 测连；成功后设为默认，导入角色卡开聊。

完整界面说明见 在 MiniTavern 中配置。

失败了？ ​

  • 测连失败、超时、空白回复 → 打开 排错对照表
  • 最常见错误：Base URL 写成了 localhost，或手机与电脑不在同一 Wi‑Fi
