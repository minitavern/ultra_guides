Bildverbindung in MiniTavern ​

App-Pfad: Einstellungen → Bildgenerierung → Bildverbindung.

Parameter, Antwortbilder, Keywords: Modellverbindung · Bild.

Neue Bildverbindung ​

  1. MiniTavern → unten Einstellungen.
  2. Bildgenerierung → Bildverbindung.
  3. Neu.
  4. Plattform, Base URL / API Key / Modell je Plattform.
  5. Testen, speichern, ggf. als Standard.

Lokal A1111 ​

Zuerst A1111 mit --api --listen.

FeldBeispiel
PlattformA1111(SD WebUI) (oder Custom A1111)
Base URLhttp://YOUR_PC_IP:7860
API Keymeist leer; bei --api-auth laut Hinweis
Modellleer oder Checkpoint-Name aus WebUI (App-Liste)

YOUR_PC_IP = LAN-IP.
Nicht http://127.0.0.1:7860 (das ist der PC, nicht das Handy).

Lokal ComfyUI ​

Zuerst ComfyUI mit --listen.

FeldBeispiel
PlattformComfyUI (oder Custom ComfyUI)
Base URLhttp://YOUR_PC_IP:8188 (Desktop oft :8000)
API Keymeist leer
Modell / Checkpointaus der App-Liste; Datei muss auf dem PC liegen

Test fehlgeschlagen: dieselbe Base URL im Handy-Browser — Firewall oder fehlendes Listen?

Bild im Chat ​

Default-Bildverbindung (Hauptchat-Modell auch nötig für Analyse/Prompt-Rewrite):

EinstiegHinweis
/imagine Promptfreies Bild. Hauptmodell: dialogbezogen («Selfie von dir» → Dialog + Charakterreferenz) oder unabhängig («Foto eines Hundes»). Anhänge im Eingabefeld: Modell sieht sie beim Promptschreiben und als Referenz; Charakter-/User-Bild-Entscheidung bleibt separat. Anhänge in der kleinen Bubble-Vorschau. Anzahl: Bildeinstellungen → Generierungsanzahl. Fehler bleibt, Retry möglich
/imagine scene oder Anhang → Nach Storyaktuelle Szene aus kürzlichem Dialog, fest 1
/imagine last oder Anhang → Nach letzter Nachrichtnach letzter Nachricht, fest 1
/imagine background oder Anhang → HintergrundUmgebung, fest 1
Lang drücken → Bildnach dieser Bubble, fest 1
Antwortbilder (intelligent / Keyword)in Bildeinstellungen «Antwortbilder» an und Auslöser wählen. Normale Nachrichten (mit Anhang) → Bypass-Bild, fest 1; Anhang = Stil

Ohne Bildverbindung: vier Anhang-Modi oder /imagine → «Zu Einstellungen / Abbrechen», kein Toast, Eingabe bleibt. Intelligent/Keyword ohne Verbindung: Toast. Antwortbilder-Schalter ohne Verbindung: Modal, Schalter bleibt aus.

Nur Bild ohne Chat-Modell: Einstiege mit Rewrite scheitern.
