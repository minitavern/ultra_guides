模型连接与参数 ​

BYOK：密钥保存在本机安全存储；请求直连你配置的地址。

模型连接 ​

路径：设置 → 模型连接

操作说明
新建平台、密钥、Base URL、模型
编辑 / 复制 / 删除列表右侧菜单
设为默认新对话默认使用
测连保存前或编辑页「测试」

平台类型（常见） ​

选项（文案以 App 为准）用途
各云厂商预设自动填国内/国际站 Base URL
自定义 (OpenAI 协议)本地 Ollama / LM Studio、兼容网关
自定义 Gemini / Anthropic对应协议端点

多站点平台可切换「使用国际站」。本地模型详见 连接 MiniTavern 与 工具总览。

模型设置（全局参数） ​

路径：设置 → 模型设置

常见项（名称以 App 为准）：

  • 记忆长度（历史条数相关）
  • 回复令牌（max tokens；部分 Claude 场景不要设为 None）
  • Temperature、Top-P / Top-K
  • 是否流式输出

会话级覆盖 ​

路径：对话页 → 设置 → 模型连接 / 参数

可为单聊指定连接与采样，不改全局默认。

聊天设置里的识图 ​

路径：设置 → 聊天设置 → 识图设置

  • 关闭「图片描写」：多模态直接把图送给模型（模型需支持视觉）。
  • 开启：先描写再主模型（描写结果会缓存复用）。

若报「当前模型不支持图片」，见 错误排错 · visionUnsupported。

排错入口 ​

测连或聊天失败 → Toast / 气泡 → 查看详情（错误代码 + 原因 + 建议）→ 对照 错误代码排错。
