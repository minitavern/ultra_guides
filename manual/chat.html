概览模型角色聊天进阶

聊天 ​

路径：底部 Tab 聊天；对话页为单会话主界面。

会话列表 ​

  • 搜索、置顶、克隆、删除会话。
  • 可导出 / 导入聊天存档（见 备份与存档）。

对话页常用操作 ​

操作说明
发送用户消息 → 请求模型 → 流式或完整显示回复
附件图输入区加号 → 相册 / 拍照（需模型或识图流程支持）。若输入是 /imagine …，附图只作生图参考，不会当成用户消息发出
/imagine斜杠生图：主模型先分析是否与对话有关、要不要角色/用户参考，再去生图。张数仅此项读取生图设置。失败会留下气泡，可点重试
续写在当前助手回复末尾继续生成
重生成替换最近助手回复（以 UI 为准）
智能回复生成建议填入输入框，不直接变成助手消息
取消取消进行中的生成
重新开始清空并按开场白重开

开场白若有多条，开聊时可选择。

气泡菜单 ​

长按或菜单：复制、编辑、隐藏、删除等。隐藏消息通常不再展示（对上下文的影响以实现为准）。

聊天设置（按会话） ​

入口：对话页右上角或设置入口 → 聊天设置。

子项（文案以 App 为准）作用
角色详情查看本聊角色快照 / 导出等
用户身份跟随默认人设或指定
语言模型跟随默认语言模型或指定连接 / 参数
生图模型跟随默认生图，或单独选连接、生图设置与关键词规则
正则多选全局正则组；空选 = 关闭
世界书多选全局世界书；空选 = 不注入
变量管理本聊 / 全局宏变量
前端渲染HTML / 脚本相关开关
识图与显示 / 背景识图（图片描写、识人、历史原图深度）与聊天外观
导出存档导出本聊 ZIP

出错时 ​

气泡错误态可打开 查看详情，对照 错误代码排错。斜杠生图失败会留在原气泡上，点重试即可再生成。
