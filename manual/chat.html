本页目录

聊天 ​

路径：底部 Tab 聊天；对话页为单会话主界面。

会话列表 ​

  • 搜索、置顶、克隆、删除会话。
  • 可导出 / 导入聊天存档（见 备份与存档）。

对话页常用操作 ​

操作说明
发送用户消息 → 请求模型 → 流式或完整显示回复
附件图输入区加号 → 相册 / 拍照（需模型或识图流程支持）
续写在当前助手回复末尾继续生成
重生成替换最近助手回复（以 UI 为准）
智能回复生成建议填入输入框，不直接变成助手消息
取消取消进行中的生成
重新开始清空并按开场白重开

开场白若有多条，开聊时可选择。

气泡菜单 ​

长按或菜单：复制、编辑、隐藏、删除等。隐藏消息通常不再展示（对上下文的影响以实现为准）。

聊天设置（按会话） ​

入口：对话页右上角或设置入口 → 聊天设置。

子项（文案以 App 为准）作用
角色详情查看本聊角色快照 / 导出等
用户身份跟随默认人设或指定
模型连接 / 参数跟随全局或覆盖
正则多选全局正则组；空选 = 关闭
世界书多选全局世界书；空选 = 不注入
变量管理本聊 / 全局宏变量
前端渲染HTML / 脚本相关开关
背景 / 布局聊天外观
导出存档导出本聊 ZIP

出错时 ​

气泡错误态可打开 查看详情，对照 错误代码排错。
