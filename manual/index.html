用户手册 ​

欢迎使用 MiniTavern Ultra（超迷你酒馆）。本手册面向终端用户，按真实菜单路径说明如何使用；实现细节见开发文档，不在此展开。

产品是什么 ​

  • 创造伙伴 × 角色扮演：从一张角色卡开始——日常陪伴或入戏演故事，由你选择。
  • BYOK：自备 API Key，直连你选择的云厂商或本地 OpenAI 兼容服务。
  • 三角色动线：底部 Tab 角色卡 · 聊天 · 设置。
  • 数据优先本地：角色、聊天、世界书等主要存在本机；备份可导出。

建议阅读顺序 ​

顺序章节适合谁
1第一次使用所有新用户
2模型连接要连云端或本地模型
3角色卡导入 / 开聊
4聊天日常对话与会话设置
5世界书 · 正则 · 人设进阶配置
6备份与存档 · 设置与其它数据与偏好
7错误代码排错测连失败、气泡报错
