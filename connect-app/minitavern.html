在 MiniTavern 中配置 ​

本文对应 App 内路径：设置 → 模型连接（开发文档称「模型连接 / 配置 AI」）。

截图可随版本更新替换；以下以文字步骤为准。

新建连接 ​

  1. 打开 MiniTavern → 底部 设置。
  2. 进入 模型连接。
  3. 点右上角 新建。
  4. 模型平台 选择 自定义（OpenAI 兼容 / 自定义 Base URL，以当前版本选项文案为准）。
  5. 填写：
字段Ollama 示例LM Studio 示例
别名家里OllamaLM Studio
Base URLhttp://192.168.1.8:11434/v1http://192.168.1.8:1234/v1
API Key可留空或填 ollama可留空
默认模型名llama3.2:3b与 Local Server 中的模型 id 一致
  1. 保存。若支持 测连，先测连再设为默认。

设为默认并开聊 ​

  1. 在模型连接列表中，将该连接设为 默认。
  2. 导入或选择一张角色卡，进入聊天发送一条消息。
  3. 电脑端 Ollama / LM Studio 应出现请求活动；App 内应流式或完整收到回复。

会话级覆盖（可选） ​

若某个聊天要临时换本地模型：聊天设置里的模型连接 / 参数可覆盖全局默认（见产品内「聊天设置」）。

示例配置汇总 ​

Ollama ​

text
Base URL:  http://YOUR_PC_IP:11434/v1
Model:     llama3.2:3b
API Key:   （空或占位）

LM Studio ​

text
Base URL:  http://YOUR_PC_IP:1234/v1
Model:     （Local Server 显示的模型 id）
API Key:   （空或占位）

注意 ​

  • 禁止 在手机上填 http://localhost:... 或 http://127.0.0.1:...。
  • URL 末尾建议带 /v1，不要填到 /chat/completions。
  • 电脑休眠、合盖、切网络后 IP 可能变化，连不上时先重新确认 IP。

连不上时请看 排错对照表。
